# fixpot's Server Playtime

A lightweight client-side Fabric mod that automatically tracks how long you play on each Minecraft server.

## Features

- Automatically tracks playtime separately for every server
- Shows your total server playtime in local chat after joining
- Saves progress locally every minute and when you disconnect
- No menus
- No keybinds
- No commands
- No configuration required
- Fully client-side
- Servers do not need the mod installed

## Requirements

- Minecraft 26.2
- Fabric Loader
- Fabric API
- Java 25

## Storage

Playtime is stored locally in `config/fixpots-server-playtime.json`.
